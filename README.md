The Investment Challenge Game is a two-player Java console game where players invest ₹10,000 in stocks, bonds, gold, and cryptocurrency over three rounds. Players can buy, sell, and track investments as market prices change randomly. The winner is determined by comparing their total wealth.

# Investment Challenge Game

A two-player, console-based investment game developed using Java and Object-Oriented Programming (OOP).

## About the Project

The game allows two players to compete by investing their money in different assets over three rounds. Players can buy and sell assets while market prices change randomly after each round. The player with the highest total wealth at the end wins.

## Features

- Two-player, turn-based gameplay
- Initial balance of ₹10,000 per player
- Four investment options: stocks, bonds, gold, and cryptocurrency
- Buy and sell assets
- View market prices and portfolio holdings
- Random market price fluctuations
- Automatic winner calculation based on total wealth
- Three rounds of gameplay

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Random utility

## OOP Concepts Demonstrated

- **Encapsulation:** Player data is kept private and accessed through methods.
- **Inheritance:** Asset subclasses inherit from the abstract asset class.
- **Abstraction:** The abstract class defines common asset behaviour.
- **Polymorphism:** Different asset classes implement the same method.
- **Interface:** The `tradable` interface defines asset valuation behaviour.

## How to Run

1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open Command Prompt in the project folder.
4. Compile the Java file:

   javac game.java
 

5. Run the game:
   java game

## Objective

Make smart investment decisions, manage your money, and build the highest total wealth before the game ends.

## Project Type

Academic project developed to practise Java programming and Object-Oriented Programming concepts.
